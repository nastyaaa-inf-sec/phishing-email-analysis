# 🎣 Анализ образца фишингового письма

**Автор:** nastyaaa-inf-sec
**Дата анализа:** 19.10.2026

## 📝 Описание проекта
Данный репозиторий содержит практический пример анализа реального фишингового письма. Цель работы — выявление индикаторов компрометации, разбор почтовых заголовков и анализ инфраструктуры злоумышленника с использованием бесплатных инструментов.
> !Важно: все скнишоты и описания действий, а так же подробный отчет - содержатся в pdf файле!

> ⚠️ **Внимание:** Все действия проводились в изолированной среде исключительно в образовательных целях. Вредоносные ссылки не открывались в браузере напрямую.

## 🛠 Используемые инструменты
*   **GitHub (rf-peixoto/phishing_pot)** — источник реального образца письма в формате `.eml`.
*   **Блокнот / текстовый редактор** — для чтения исходного кода письма и анализа заголовков.
*   **urlscan.io** — для безопасной проверки домена и ссылок (без перехода на фишинговый сайт).

## 🔍 Ключевые моменты
Анализ показал, что письмо является фишинговым. Злоумышленники используют методы социальной инженерии и подделку адреса отправителя. 

**Ключевые индикаторы компрометации и выявленные аномалии:**
1. **Провал аутентификации:** `spf=fail`.
2. **Подозрительный отправитель:** Использование технического домена Microsoft (`onmicrosoft.com`) со случайным набором символов.
3. **Автоматизированная рассылка:** Письмо отправлено программно через Google API (`with HTTPREST`).
4. **Вредоносная ссылка:** Ведет на сторонний домен `woondspiay.com`.

## 🔗 2. Анализ ссылок и инфраструктуры
В HTML-коде письма (внутри тега `<a>`) была обнаружена замаскированная гиперссылка, ведущая на кнопку «CLAIM SPINS».

*   **Обнаруженный URL:** `https://woondspiay.com/index.php?search=...` (ссылка содержит уникальные параметры для отслеживания жертвы).
*   **Анализ домена:** Согласно данным сервиса **urlscan.io**, домен не является популярным ресурсом, ранее не сканировался, но был зарегистрирован более года назад. Это характерно для «спящих» доменов, которые покупаются заранее для обхода антиспам-фильтров.
*   **Анализ изображений:** Для отрисовки кнопки используется бесплатный хостинг картинок (`i.imgur.com`), что не свойственно крупным корпорациям.

## 🛡 3. Заключение и рекомендации
Письмо представляет собой классическую фишинговую атаку, направленную на кражу данных.

**Рекомендации по защите:**
*   **Пользователям:** Не переходить по ссылкам, не вводить личные данные. Пометить письмо как спам/фишинг.
*   **Службе безопасности (SOC):** Заблокировать домен `woondspiay.com` и IP-адрес `209.85.208.54` на почтовом шлюзе. Настроить правила фильтрации для писем с проваленным SPF от домена `onmicrosoft.com`.
